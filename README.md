# RECOIL RUMBLE

A 2–4 player platform fighter where your gun is your movement: every shot pushes you the other way.
Play locally or online with friends, on Android and Windows. Both versions can play together.

## Download

**[⬇ Get the latest version](https://github.com/ido1224/recoil-rumble/releases/latest)**

- **Android / tablet:** download `recoil-rumble.apk` and open it. If the phone asks, allow
  "install unknown apps" for your browser. Newer versions install over the old one.
- **Windows:** download `RecoilRumble.exe` and run it. If Windows SmartScreen warns you, click
  **More info → Run anyway** (the game isn't code-signed).

## Play online

One player taps **Host** and shares the room code; everyone else taps **Join** and enters it.
