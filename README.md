# RECOIL RUMBLE

A 2–4 player platform fighter where your gun is your movement: every shot pushes you the other way.
Play with bots or online with friends. **Android and Windows can play together.**

# 👉 [DOWNLOAD HERE](https://github.com/ido1224/recoil-rumble/releases/latest) 👈

On that page, scroll down to **Assets** and tap the file for your device.

---

## 📱 Android (phone or tablet)

1. Tap **`recoil-rumble.apk`** to download it (about 27 MB).
2. When it finishes, tap **Open** (or open it from your notifications / Downloads).
3. If your phone says **"not allowed to install unknown apps"**:
   tap **Settings** → turn on **Allow from this source** → go back.
4. Tap **Install**.
5. If **Google Play Protect** pops up, tap **More details → Install anyway**.
   (It does this for any game that isn't from the Play Store.)
6. Tap **Open**. Done!

**Updating later:** download the new `recoil-rumble.apk` and install it the same way.
It installs over the old one, and you keep your unlocks.

## 💻 Windows PC

1. Click **`RecoilRumble.exe`** to download it (about 100 MB).
2. If your browser warns that the file **"isn't commonly downloaded"**:
   click **⋯** (or the arrow) → **Keep** → **Keep anyway**.
3. Open the file. If a blue **"Windows protected your PC"** box appears:
   click **More info** → **Run anyway**.
4. The game opens in full screen. **F11** switches to a window, **QUIT** is in the menu.

No install needed: the `.exe` *is* the game. Put it on your desktop and double-click it to play.
**Updating later:** download the new `RecoilRumble.exe` and replace the old one.

## 🎮 Playing online together

**One person hosts:**
1. Type your name under **ONLINE**.
2. Tap **HOST A ROOM**.
3. Tap **Copy code** and send the code to your friends (privately: the last 6 digits are the room password).
4. When everyone is in the list, tap **Start match**.

**Everyone else joins:**
1. Type your name under **ONLINE**.
2. Paste the code into the code box (tap **PASTE**).
3. Tap **JOIN**.

Nobody can see anyone else's IP address.

## ❓ Help

- **"App not installed" on Android:** delete the old RECOIL RUMBLE app, then install again.
- **Can't join a room:** make sure you copied the *whole* code, and that the host is still on the HOSTING screen.
- **How do I play?** Main menu → **HOW TO PLAY**. Controls can be changed under **CONTROLS**.
